# 在线文档混合 RAG

AI 问答使用关键词检索和向量语义检索组合召回相关段落，再交给原有聊天模型回答。未配置向量服务、服务不可用或文档尚未建立向量时，关键词检索继续可用。上传的 PDF、Word、图片及课堂文件尚不参与正文检索。

## 开启

1. 完成数据库迁移后，最高管理员进入「管理中心 → AI 服务 → 资料检索 → 配置向量模型」。
2. 选择支持 OpenAI 兼容 `POST /embeddings` 接口的服务商，填写 Embedding 模型 ID 和专用 API Key。该模型与回答使用的聊天模型分别配置，聊天服务商不一定提供 Embedding。
3. 勾选「开启语义检索」，点击「验证并保存」。服务端发送固定测试文字，验证返回的浮点向量及维度。支持 1–4096 维，不强制传入供应商可能不支持的 dimensions 参数。
4. 管理页显示已完成、待处理、失败文档数和片段数。页面打开时会持续推进当前同步；失败文档可用「重试并同步」恢复。

启用后，在线文档正文会发往所选向量服务。API Key 加密保存，管理接口不返回其内容。修改服务地址后必须重新填写密钥，防止旧服务的密钥发送到新地址。

连接测试期间若其他管理员修改了配置，保存会返回 409 并要求刷新重试，避免服务地址、密钥与索引版本错配。

## 数据库与部署

新迁移 `20261024000000_hybrid_rag` 安装 vector 扩展并新增配置、文档索引及片段表，保留全部历史 migration。没有配置向量模型时功能默认关闭。

- **Neon / Vercel**：构建时照常执行 `db:deploy`。Neon 提供 pgvector，数据库迁移角色须有创建扩展的权限。
- **自托管 Release**：生产继续使用离线 `.run` 升级。包内附带 `liveboard-postgres:16-pgvector0.8.1`，基于原 PostgreSQL 16 Alpine 编译校验过的 pgvector 源码；沿用现有数据卷，禁止删除卷。安装器继续在 schema 迁移前备份数据库。
- **本地开发**：`pnpm infra:up` 构建 pgvector PostgreSQL 镜像并启动基础设施，然后执行 `pnpm --filter @liveboard/api db:deploy`。已有本地 PostgreSQL 则先安装与 PostgreSQL 主版本匹配的 pgvector 扩展文件。
- **跨环境数据迁移**：pg_dump/restore 包含向量扩展与表，目标需提供扩展。导入时清空向量密钥、关闭语义检索并释放旧租约，管理员重新配置后才能启用。

## 索引和一致性

分段以在线文档内容块为基础，超长块按最多 1200 个 Unicode 字符切分并重叠 160 字符，保留最近标题及文档标题用于嵌入。每批最多 16 段，游标保存在数据库中；失败后可从已完成位置继续。

索引由文档写请求、问答和管理员同步触发，现有每日 Cron 也会推进。每次调用预算为 45 秒；大批量首次建库可保持管理页打开，或由外部定时任务调用已有的 `/internal/cron/daily`（Bearer CRON_SECRET）。关闭浏览器不会撤销已经注册的后台批次，剩余工作由下一次触发继续。Vercel 使用 waitUntil，不自调用接力，不依赖常驻定时器。

检索使用 pgvector 精确余弦搜索，先限制可见文档再取候选，避免近似索引在权限过滤后丢失候选。向量候选与关键词结果按 RRF 合并，语义候选的最低余弦相似度为 0.35。该阈值是初始默认值，实际效果应使用所选模型和真实问题评估；当前实现未针对百万级片段做性能基准。

文档版本与配置 generation 必须匹配，旧索引不进入回答。权限在检索前和发给回答模型前均检查；删除文档时数据库级联清理索引。更换模型、地址或维度会重建索引，不能混用不同模型的向量。索引租约有 token 校验，过期任务不能覆盖新任务。

## 验证

`pnpm validate` 包含纯函数、接口校验和配置测试。真实 pgvector 测试需在**专用测试数据库**迁移后运行：

```bash
RUN_RAG_TESTS=true pnpm --filter @liveboard/api exec dotenv -e ../../.env -- \
  jest src/modules/ai/ai-rag.integration.spec.ts --runInBand --coverage=false
```

CI 集成作业会自动执行。测试只创建并清理自己的数据，使用合成向量，不调用付费 AI；覆盖无关键词的语义命中、权限过滤、权限中途撤销、编辑与删除失效、分片失败续建、模型切换竞争和服务失败回退。真实模型的中文召回质量需在配置实际服务后另行验收。
